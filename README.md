# ⏰ Pure Clock (UkrAlarm)

> **Розумний будильник для Android із захистом під час повітряних тривог в Україні та преміальним скляним інтерфейсом (Glassmorphism).**

---

## ✨ Основні можливості

- 🛡️ **Розумна перевірка тривог (Anti-Alert System)**:
  Перед спрацьовуванням будильник автоматично перевіряє актуальний статус тривоги в обраній області та районі (через Ubilling API). Якщо оголошено повітряну тривогу, сигнал автоматично відкладається до моменту офіційного відбою.
  
- 💎 **Сучасний скляний інтерфейс (iOS 26 / Material 3 Style)**:
  - Заокруглені скляні картки та шторки (`BottomSheet`) із напівпрозорим ефектом розмиття.
  - Чорна (глибокий OLED `#000000`) та біла теми із **плавним кінематографічним крос-фейдом (cross-dissolve)** без спалахів та стрибків скролу.
  - Приємний тактильний відгук (Haptics) при кожній взаємодії.

- ⏱️ **Барабан вибору часу (Wheel Time Picker)**:
  Плавне інерційне прокручування годин та хвилин у стилі iOS із легким клацанням вібрації на кожному значенні.

- 📅 **Фірмовий скляний календар**:
  Інтерактивний місячний календар для встановлення будильника на конкретну дату із кнопкою швидкого скидання.

- 🕒 **Живий віджет на робочий стіл (2×2)**:
  - Нативний аналоговий годинник `AnalogClock`, стрілки якого обертаються системою в реальному часі **з нульовим навантаженням на батарею**.
  - Інформаційна плашка з найближчим будильником (`⏰ 07:00`) та статусом тривоги (`🟢 Відбій` / `🔴 Тривога`).
  - Швидкий перехід у додаток чи налаштування в один дотик.

- 🔔 **Гнучке налаштування дзвінка**:
  - Налаштування паузи (Snooze): вибір інтервалу (5, 10, 15, 30 хв або довільні хвилини) та кількості повторів.
  - Вибір вібрації (Базова, Серцебиття, Тік-так) з живим прев'ю.
  - Режим редагування: масове виділення, ввімкнення, вимкнення чи видалення будильників.

- 🌍 **Повна багатомовність**:
  Підтримка трьох мов: **Українська**, **English**, **Русский** із миттєвим перемиканням у додатку.

## 🛠 Технології та архітектура

- **Мова**: Kotlin 1.9
- **Платформа**: Android SDK (Min SDK: 26, Target SDK: 34)
- **UI & Components**: AndroidX, Material Design 3, CoordinatorLayout, ConstraintLayout, Wheel RecyclerViews
- **Архітектура**: Foreground Service + AlarmManager (`setAlarmClock`), SQLite Room/OpenHelper
- **Фонові оновлення**: BroadcastReceiver для запуску після перезавантаження (`BOOT_COMPLETED`) та AppWidgetProvider

## 🚀 Як зібрати проєкт

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/YOUR_USERNAME/UkrAlarm.git
   cd UkrAlarm
   ```
2. Відкрийте в **Android Studio** або зберіть APK через консоль:
   ```bash
   ./gradlew assembleDebug
   ```
3. Готовий APK буде створено за шляхом:
   `app/build/outputs/apk/debug/app-debug.apk`
